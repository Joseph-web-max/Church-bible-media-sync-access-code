How to use the code

  1. Control room: open index.html and sign in with your username, password and access code.
  2. Projector: open generate.html on the screen computer and enter the access code.

Keep this page and the other files in the same folder. Open them through http://localhost or https, not by double-clicking, so that encryption works.
